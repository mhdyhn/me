# میتی — مربی تمرین باشگاه

میتی یک همراه تمرینی شخصی، فارسی و موبایل‌محور است. برنامهٔ هفتگی، آموزش حرکت‌ها، ثبت تمرین و زمان استراحت، راهنمای پیشرفت تدریجی، سوابق، وزن بدن و یادداشت‌های تغذیه را در یک برنامهٔ وب قابل‌نصب گرد هم می‌آورد.

## قابلیت‌ها

- **برنامهٔ تمرینی:** پنج جلسهٔ اصلی پرس ۱، کشش ۱، پا ۱، بالاتنه ۲ و پایین‌تنه ۲؛ به‌علاوهٔ یک جلسهٔ اختیاری و کم‌خستگی برای حرکات کمکی و یادآوری روز استراحت.
- **آموزش حرکت‌ها:** راهنمای آماده‌سازی، تنظیم دستگاه و سیم‌کش، مراحل حرکت، تنفس، سرعت اجرا، نکته‌های ایمنی، اشتباه‌های رایج و نسخهٔ هر حرکت.
- **نمایشگر سه‌بعدی حرکت:** یک مدل انسانیِ پوشیده و rigged با مجوز CC0 در برنامه است و صفحهٔ هر حرکت، حلقهٔ پویانمایی همان حرکت را روی اسکلت همین مدل پخش می‌کند: کنترل پخش/توقف، شروع دوباره، سرعت ۰٫۵/۱/۱٫۵ و سه زاویهٔ روبه‌رو، پهلو و پشت. کنار نمایشگر، مرحلهٔ فعلی حرکت و «استانداردهای فرم همین حرکت» نشان داده می‌شود. پویانمایی از کتابخانهٔ حرکت خود برنامه ساخته می‌شود (کلیپ آمادهٔ بیرونی وجود ندارد) و راهنمای فرم است، نه جایگزین مربی یا ویدیوی اجرای واقعی. منشأ و اثر انگشت فایل مدل در `public/models/README.md` ثبت شده است.
- **ثبت تمرین:** ثبت وزنه، تکرار، تکرار در ذخیره (RIR) و یادداشت ست؛ نمایش عملکرد ثبت‌شدهٔ قبلی؛ ذخیرهٔ جلسهٔ فعال؛ و زمان‌سنج استراحت با مکث، پایان زودهنگام و تنظیم ۱۵ ثانیه‌ای.
- **پیشرفت دوگانه:** تنها پس از رسیدن همهٔ ست‌های برنامه‌ریزی‌شده به بیشترین تکرار بازه و حفظ حداقل RIR تعیین‌شده، افزایش کوچک وزنه را برای بررسی پیشنهاد می‌کند. برنامه هرگز وزنه را خودکار بالا نمی‌برد.
- **پیشرفت و سوابق:** سوابق جلسه، ست‌های ثبت‌شده، بهترین ست‌ها، نمودار وزنهٔ کاری و روند وزن بدن.
- **تغذیه:** هدف‌های قابل‌تنظیم کالری و درشت‌مغذی‌ها، ثبت روزانهٔ خوراک و بازهٔ پروتئین بر اساس وزن فعلی پروفایل. نیاز کالری قطعی یا تجویز پزشکی فرض نمی‌شود.
- **ذخیره‌سازی محلی و نصب‌پذیری:** تمرین‌ها و پروفایل در IndexedDB همین دستگاه ذخیره می‌شوند. پوستهٔ برنامه و فایل مدل مرجع در نسخهٔ نصب‌شده برای دسترسی آفلاین cache می‌شوند؛ کد سه‌بعدی فقط هنگام بازکردن نمایشگر بارگیری می‌شود.
- **پشتیبان‌گیری:** از بخش پروفایل و تنظیمات، نسخهٔ JSON از پروفایل و گزارش‌ها دریافت کن.
- **رابط فارسی و راست‌به‌چپ:** نوشته‌ها، تاریخ‌های نمایشی، اعداد و چیدمان رابط برای زبان فارسی تنظیم شده‌اند؛ قالب تاریخ‌های ذخیره‌شده همچنان ISO/Gregorian باقی می‌ماند تا سازگاری داده‌ها حفظ شود.

وزنه‌هایی که در پروفایل اولیه گزارش شده‌اند فقط **برآوردهای تأییدنشدهٔ وزنهٔ کاری** هستند؛ نه رکورد یک‌تکرار بیشینه، نه ست ثبت‌شده، نه عملکرد قبلی و نه رکورد شخصی. هیچ سابقه یا رکوردی ساختگی نیست.

## فناوری‌ها

- React 19، TypeScript و Vite 8
- React Router برای مسیرهای برنامه
- Dexie و IndexedDB برای ذخیره‌سازی محلی
- Three.js و React Three Fiber برای نمایشگر سه‌بعدی اختیاری و تنبل
- افزونهٔ Vite PWA و Workbox برای نصب‌پذیری و ذخیرهٔ فایل‌ها در حافظهٔ آفلاین
- قلم Vazirmatn به‌صورت محلی از بستهٔ npm؛ بدون وابستگی به سرویس قلم خارجی در زمان اجرا
- Vitest، Testing Library و fake-indexeddb برای آزمون‌ها
- CSS واکنش‌گرا و اختصاصی؛ بدون تصویر خارجی یا دارایی دارای حق نشرِ تأییدنشده

## پیش‌نیازها

- Node.js نسخهٔ **22.12 یا بالاتر**
- npm نسخهٔ ۱۰ یا بالاتر

## نصب و اجرا

```bash
npm ci
npm run dev
```

Vite روی `0.0.0.0` اجرا می‌شود تا از دستگاه‌های دیگر شبکه و محیط پیش‌نمایش نیز در دسترس باشد. برای آزمایش با تلفن همراه در همان شبکه، نشانی LAN رایانه را باز کن و در صورت نیاز دسترسی سرور توسعه را در دیوارهٔ آتش مجاز کن.

## فرمان‌ها

```bash
npm run dev       # اجرای سرور توسعه
npm run build     # بررسی TypeScript و ساخت نسخهٔ نهایی
npm test          # اجرای آزمون‌ها
npm run test:watch
npm run preview   # اجرای محلی نسخهٔ ساخته‌شده
```

## متغیرهای محیطی

نیازی به متغیر محیطی نیست. میتی سرور، حساب کاربری، کلید API یا ابزار تحلیل شخص ثالث ندارد.

## ساختار پروژه

```text
src/
  components/       پوستهٔ مشترک، نمودارها و نمایشگر سه‌بعدی حرکت
  motion/           ریگ، کتابخانهٔ حرکت‌ها و استانداردهای فرم هر حرکت
  context/          وضعیت برنامه و عملیات ذخیره‌سازی
  data/             برنامه‌ها، اطلاعات حرکت‌ها، ترجمهٔ فارسی و پروفایل پیش‌فرض
  lib/              IndexedDB، قالب‌بندی فارسی و تحلیل تمرین
  pages/            خانه، برنامه، حرکت‌ها، تمرین، پیشرفت، تغذیه و تنظیمات
  types.ts          نوع‌های دامنه و ذخیره‌سازی
public/
  brand-mark.svg    نشان اصلی برنامه
  models/           مدل مرجع سه‌بعدی دارای مجوز CC0 و اطلاعات منشأ آن
tests/              آزمون‌های صفحه، جریان تمرین و ذخیره‌سازی
```

## داده و حریم خصوصی

داده‌ها فقط در IndexedDB مرورگر فعلی ذخیره می‌شوند و به مرورگر یا دستگاه دیگری همگام‌سازی نمی‌شوند. پاک‌کردن داده‌های سایت ممکن است آن‌ها را حذف کند. پیش از پاک‌کردن حافظه یا جابه‌جایی دستگاه، نسخهٔ JSON پشتیبان بگیر. هیچ رمز یا فایل `.env` در مخزن لازم نیست.

## دارایی سه‌بعدی و پویانمایی حرکت‌ها

`public/models/human.glb` یک مدل انسان با پوشش روزمره و ۵۳ استخوان است؛ مجوز اعلام‌شدهٔ فایل CC0 1.0 است. این فایل حدود ۶۷۲ کیلوبایت است و کلیپ پویانمایی از پیش ساخته‌شده ندارد. جزئیات منبع، مجوز و SHA-256 در `public/models/README.md` آمده است. مدل در بستهٔ آفلاین PWA نیز cache می‌شود.

پویانمایی هر حرکت، کارِ خودِ برنامه روی همین ریگ است، نه یک دارایی واردشده:

```text
src/motion/types.ts       قراردادهای حرکت، تجهیزات، سکو و استانداردهای فرم
src/motion/skeleton.ts    خواندن حالت استراحت مدل و محور لولاهای واقعی
src/motion/sampler.ts     نمونه‌گیری حلقه و نوشتن آن روی استخوان‌ها + حل تماس با زمین
src/motion/armPoses.ts    زاویه‌های شانه و آرنج برازش‌شده (تولیدشده، دستی ویرایش نکن)
src/motion/library.ts     ۳۲ حرکت فارسی، هر کدام با حلقهٔ پنج‌کلیدی و استانداردهای فرم
src/motion/modelRig.ts    اتصال حلقه به صحنهٔ بارگیری‌شده در مرورگر
tools/arm-solve.ts        حل‌کنندهٔ آفلاین زاویه‌های بازو
tools/motion-report.ts    گزارش عددی مفصل‌ها برای بازرسی یک حرکت
```

افزودن حرکت تازه: یک سازنده در `src/motion/library.ts` بنویس، `motionId` را در `src/data/exercises.ts` به آن حرکت بده و `npm test` بگیر. تست‌های `tests/motion-library.test.ts` و `tests/motion-rig.test.ts` پایداری تبدیل‌ها، تماس کف پا با زمین، وجود هر پنج مرحله و قابل‌پخش‌بودن حلقه روی ریگ را بررسی می‌کنند.

افزودن کلیپ آمادهٔ بیرونی (اختیاری، برای آینده): هر دارایی تازه باید منشأ، مجوز بازتوزیع، ریگ سازگار و تناسب با همان تمرین داشته باشد و باید در `public/models/README.md` ثبت شود. انیمیشن مشابه یا تصادفی را به‌جای فرم همان حرکت جا نزن؛ اگر کلیپی موجود نیست، همان نمایش ریگ‌محور و راهنمای نوشتاری کافی است.

## ساخت و استقرار

```bash
npm ci
npm run build
```

پوشهٔ `dist/` را روی هر میزبان ایستای HTTPS که مسیریابی SPA را پشتیبانی می‌کند منتشر کن؛ مسیرهای ناشناخته باید به `/index.html` برگردند. سرویس‌ورکر PWA هنگام ساخت نسخهٔ نهایی تولید می‌شود. سرور یا پیکربندی محیطی جداگانه لازم نیست.

## یادآوری ایمنی

میتی آموزش و ثبت عمومی تمرین ارائه می‌دهد و جایگزین توصیهٔ پزشکی یا تشخیص فردی نیست. از وزنه و دامنه‌ای استفاده کن که کنترل می‌کنی؛ اگر حرکتی درد تیز ایجاد کرد، متوقف شو و در صورت نیاز از متخصص واجد صلاحیت راهنمایی بگیر.
