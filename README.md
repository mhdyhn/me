# میتی — مربی تمرین باشگاه

میتی یک همراه تمرینی شخصی، فارسی و موبایل‌محور است. برنامهٔ هفتگی، آموزش حرکت‌ها، ثبت تمرین و زمان استراحت، راهنمای پیشرفت تدریجی، سوابق، وزن بدن و یادداشت‌های تغذیه را در یک برنامهٔ وب قابل‌نصب گرد هم می‌آورد.

## قابلیت‌ها

- **برنامهٔ تمرینی:** برنامهٔ هفتگی RAGE با شش جلسه: روزهای ۱، ۲، ۳، ۵، ۶ و ۷ (سینه و سرشانه، پشت و جلو بازو، پا و شکم، و تکرار آن‌ها)، روز ۴ استراحت است. هر جلسه یک کارت کاردیوی پایانی دارد که فقط یادآوری است و در ثبت ست‌ها نمی‌آید. هر حرکت با نام و توضیح‌های نوشتاری‌اش نمایش داده می‌شود.
- **آموزش حرکت‌ها:** راهنمای آماده‌سازی، تنظیم دستگاه و سیم‌کش، مراحل حرکت، تنفس، سرعت اجرا، نکته‌های ایمنی، اشتباه‌های رایج و نسخهٔ هر حرکت. مراحل حرکت به‌صورت فهرست نوشتاری و قابل مرور نمایش داده می‌شوند.
- **ثبت تمرین:** ثبت وزنه، تکرار، تکرار در ذخیره (RIR) و یادداشت ست؛ نکته‌های فرم همین حرکت در همان کارت تمرین و به‌صورت تاشو در دسترس‌اند؛ نمایش عملکرد ثبت‌شدهٔ قبلی؛ ذخیرهٔ جلسهٔ فعال؛ و زمان‌سنج استراحت با مکث، پایان زودهنگام و تنظیم ۱۵ ثانیه‌ای.
- **پیشرفت دوگانه:** تنها پس از رسیدن همهٔ ست‌های برنامه‌ریزی‌شده به بیشترین تکرار بازه و حفظ حداقل RIR تعیین‌شده، افزایش کوچک وزنه را برای بررسی پیشنهاد می‌کند. برنامه هرگز وزنه را خودکار بالا نمی‌برد.
- **پیشرفت و سوابق:** سوابق جلسه، ست‌های ثبت‌شده، بهترین ست‌ها، نمودار وزنهٔ کاری و روند وزن بدن.
- **تغذیه:** هدف‌های قابل‌تنظیم کالری و درشت‌مغذی‌ها، ثبت روزانهٔ خوراک و بازهٔ پروتئین بر اساس وزن فعلی پروفایل. نیاز کالری قطعی یا تجویز پزشکی فرض نمی‌شود.
- **ذخیره‌سازی محلی و نصب‌پذیری:** تمرین‌ها و پروفایل در IndexedDB همین دستگاه ذخیره می‌شوند. پوستهٔ برنامه در نسخهٔ نصب‌شده برای دسترسی آفلاین cache می‌شود.
- **پشتیبان‌گیری:** از بخش پروفایل و تنظیمات، نسخهٔ JSON از پروفایل و گزارش‌ها دریافت کن.
- **رابط فارسی و راست‌به‌چپ:** نوشته‌ها، تاریخ‌های نمایشی، اعداد و چیدمان رابط برای زبان فارسی تنظیم شده‌اند؛ قالب تاریخ‌های ذخیره‌شده همچنان ISO/Gregorian باقی می‌ماند تا سازگاری داده‌ها حفظ شود.

وزنه‌هایی که در پروفایل اولیه گزارش شده‌اند فقط **برآوردهای تأییدنشدهٔ وزنهٔ کاری** هستند؛ نه رکورد یک‌تکرار بیشینه، نه ست ثبت‌شده، نه عملکرد قبلی و نه رکورد شخصی. هیچ سابقه یا رکوردی ساختگی نیست.

## فناوری‌ها

- React 19، TypeScript و Vite 8
- React Router برای مسیرهای برنامه
- Dexie و IndexedDB برای ذخیره‌سازی محلی
- افزونهٔ Vite PWA و Workbox برای نصب‌پذیری و ذخیرهٔ فایل‌ها در حافظهٔ آفلاین
- قلم Vazirmatn به‌صورت محلی از بستهٔ npm؛ بدون وابستگی به سرویس قلم خارجی در زمان اجرا
- Vitest، Testing Library و fake-indexeddb برای آزمون‌ها
- CSS واکنش‌گرا و اختصاصی؛ بدون تصویر خارجی یا دارایی دارای حق نشرِ تأییدنشده

## پیش‌نیازها

- Node.js نسخهٔ **22.12 یا بالاتر**
- npm نسخهٔ ۱۰ یا بالاتر

## نصب و اجرا

```bash
npm ci
npm run dev
```

Vite روی `0.0.0.0` اجرا می‌شود تا از دستگاه‌های دیگر شبکه و محیط پیش‌نمایش نیز در دسترس باشد. برای آزمایش با تلفن همراه در همان شبکه، نشانی LAN رایانه را باز کن و در صورت نیاز دسترسی سرور توسعه را در دیوارهٔ آتش مجاز کن.

## فرمان‌ها


## متغیرهای محیطی

نیازی به متغیر محیطی نیست. میتی سرور، حساب کاربری، کلید API یا ابزار تحلیل شخص ثالث ندارد.

## داده و حریم خصوصی

داده‌ها فقط در IndexedDB مرورگر فعلی ذخیره می‌شوند و به مرورگر یا دستگاه دیگری همگام‌سازی نمی‌شوند. پاک‌کردن داده‌های سایت ممکن است آن‌ها را حذف کند. پیش از پاک‌کردن حافظه یا جابه‌جایی دستگاه، نسخهٔ JSON پشتیبان بگیر. هیچ رمز یا فایل `.env` در مخزن لازم نیست.

## بهینه‌سازی بارگذاری

اپ روی پوستهٔ سبک بنا شده است تا باز کردن آن روی موبایل و اینترنت کند هم سریع بماند:

- تنها صفحهٔ خانه همراه پوسته می‌آید؛ بقیهٔ مسیرها با `React.lazy` و یک حالت انتظار فارسی بارگذاری می‌شوند.
- سرویس‌ورکر فقط پوستهٔ برنامه (JS، CSS، HTML، SVG و قلم) را نگه می‌دارد.


## ساخت و استقرار

```bash
npm ci
npm run build
```

پوشهٔ `dist/` را روی هر میزبان ایستای HTTPS که مسیریابی SPA را پشتیبانی می‌کند منتشر کن؛ مسیرهای ناشناخته باید به `/index.html` برگردند. سرویس‌ورکر PWA هنگام ساخت نسخهٔ نهایی تولید می‌شود. سرور یا پیکربندی محیطی جداگانه لازم نیست.

## یادآوری ایمنی

میتی آموزش و ثبت عمومی تمرین ارائه می‌دهد و جایگزین توصیهٔ پزشکی یا تشخیص فردی نیست. از وزنه و دامنه‌ای استفاده کن که کنترل می‌کنی؛ اگر حرکتی درد تیز ایجاد کرد، متوقف شو و در صورت نیاز از متخصص واجد صلاحیت راهنمایی بگیر.

## سرور API (فاز یک)

سرور در پوشهٔ `server/` است و با Node 22 و پایگاه داده PostgreSQL کار می‌کند.

```bash
ADMIN_USERNAME=owner ADMIN_PASSWORD='حداقل-۸-نویسه' npm run server
```

- `ADMIN_USERNAME` و `ADMIN_PASSWORD` فقط در اولین اجرا حساب مدیر را می‌سازند.
- داده‌ها در PostgreSQL ذخیره می‌شوند. روی هاست واقعی متغیر `DATABASE_URL` را برابر آدرس اتصال (مثلاً Neon) قرار بده؛ بدون آن سرور در حالت production اجرا نمی‌شود، تا داده‌ها بی‌سروصدا از دست نروند. در توسعهٔ محلی بدون `DATABASE_URL` داده‌ها در `server/data/pgdata` ذخیره می‌شوند (در Git نیستند).
- پیشرفت تمرین شاگرد از گوشی‌اش برای مربی هم فرستاده می‌شود (خلاصهٔ جلسه‌ها: تاریخ، حرکت‌ها، ست‌ها، وزنه و تکرار و اینکه جلسه کامل شد یا نه). مربی آن را از صفحهٔ «پیشرفت» هر شاگرد می‌بیند.
- پورت پیش‌فرض `8787` و آدرس `0.0.0.0` است تا پیش‌نمایش سندباکس به آن برسد. دِو سرور (`npm run dev`) درخواست‌های `/api` را به همین پورت پروکسی می‌کند. روی هاست واقعی `HOST` را تنظیم کن و سرور را پشت reverse proxy با HTTPS بگذار؛ رمز مدیر توسعه را هم عوض کن.
- مربی توسط مدیر ساخته می‌شود؛ شاگرد توسط مربی. نام کاربری و رمز موقت فقط یک‌بار نشان داده می‌شوند و کاربر باید در ورود اول رمز را عوض کند.
- در صورت پنج تلاش ناموفق برای یک نام کاربری، ورود آن نام کاربری ۱۵ دقیقه قفل می‌شود.

### مسیرهای حساب و مربی

- `/login`: ورود مربی، شاگرد و مدیر. بعد از ورود هر نقش به صفحهٔ خودش می‌رود.
- `/account/change-password`: تغییر رمز موقت (برای مربی و شاگرد الزامی است).
- `/coach`: شاگردهای مربی؛ ساخت شاگرد، بازتولید رمز. برای مدیر: فهرست و ساخت مربی.
- `/coach/students/:id/program`: ساز برنامه (روز، حرکت از کاتالوگ بر اساس گروه عضلانی، ست، تکرار، استراحت).
- `/my-program`: نمایش فقط‌خواندنی برنامه برای شاگرد.

این مسیرها خارج از پوستهٔ برنامهٔ شخصی هستند. برنامهٔ شخصی قبلی (`/`, `/program`, …) بدون تغییر ماند.
