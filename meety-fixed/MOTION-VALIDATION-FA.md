# میتی — وضعیت و اجرای اعتبارسنجی حرکت سه‌بعدی

## وضعیت این بسته

- کتابخانهٔ حرکات با کی‌فریم‌های روی ریگ نوشته می‌شود؛ در `ExerciseModelCanvas.tsx` مسیر پخش `AnimationMixer`/`clipAction` دیده نمی‌شود.
- فایل `public/models/human.glb` در بستهٔ بازسازی‌شده از patch حاضر نیست.
- در این محیط وابستگی‌های npm نصب نشده‌اند و نصب آفلاین قبلاً به علت نبودن بستهٔ `zustand@5.0.15` در کش متوقف شده است.
- به همین دلیل، این تحویل به معنی تأیید بصری یا اصلاح‌شدن قطعی فرم حرکات نیست. اسکریپت‌ها مرحلهٔ بعد را قابل‌تکرار می‌کنند.

## اجرای کامل روی ویندوز

1. پوشهٔ پروژه را روی رایانه‌ای با اینترنت باز کن؛ Node.js نسخهٔ `22.12.0` یا بالاتر لازم است.
2. PowerShell را در ریشهٔ پروژه باز کن و اجرا کن:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\RUN-MOTION-AUDIT.ps1
   ```

3. گزارش کامل در `motion-audit-log.txt` ساخته می‌شود. اسکریپت وابستگی‌ها را از lockfile نصب می‌کند، مدل را در صورت نیاز دریافت و SHA-256 آن را بررسی می‌کند، تست‌های حرکت و آناتومی و سپس همهٔ تست‌ها و هر دو build را اجرا می‌کند.
4. بعد از عبور تست‌ها، پنج حرکت را باید در نمای روبه‌رو و پهلو بازبینی کرد: اسکوات پشت با هالتر، پرس سینه با هالتر، زیربغل سیم‌کش، ددلیفت رومانیایی و پرس پا. به‌ویژه دست/مچ روی ابزار، مسیر وزنه، تماس کف پا، موقعیت نیمکت/صندلی و دامنهٔ مفصل‌ها را بررسی کن.

## دستورات مستقل

- `npm run audit:motion` — بررسی ایستای نام حرکات و مسیر پویانمایی؛ بدون رندر و بدون تأیید فرم.
- `npm run fetch:model` و سپس `npm run verify:model` — دریافت مدل pin شده و بررسی فرمت/هش.
- `npm test -- tests/motion-library.test.ts tests/motion-grip.test.ts tests/motion-anatomy.test.ts tests/model-path.test.ts` — تست‌های متمرکز حرکت.
- `npm run build:offline` و سپس `npm run verify:offline` — ساخت HTML تک‌فایلی و بررسی مقدماتی بسته‌بندی.

## معیارهای تأیید بصری

هر حرکت فقط وقتی تأیید بصری می‌شود که:

- از نمای روبه‌رو، پهلو و در صورت نیاز پشت مرور شده باشد؛
- تماس دست با هالتر/دمبل/دستهٔ دستگاه در کل مسیر حفظ شود؛
- کف پا، نیمکت و صندلی از بدن جدا یا داخل بدن فرو نروند؛
- مسیر وزنه و ترتیب خم و باز شدن مفاصل با شرح حرکت هم‌خوان باشد؛
- آغاز و پایان حلقه پرش، لغزش یا جابه‌جایی ناخواسته نداشته باشد.

تست‌های عددی به تنهایی جای این بررسی را نمی‌گیرند. به دلیل سابقهٔ آسیب شانه در مشخصات برنامه، حرکت‌های بالای سر یا دردآور نباید صرفاً با دیدن مدل به‌عنوان فرم ایمن تأیید شوند.
