# میتی — مربی تمرین باشگاه

میتی یک همراه تمرینی شخصی، فارسی و موبایل‌محور است. برنامهٔ هفتگی، آموزش حرکت‌ها، ثبت تمرین و زمان استراحت، راهنمای پیشرفت تدریجی، سوابق، وزن بدن و یادداشت‌های تغذیه را در یک برنامهٔ وب قابل‌نصب گرد هم می‌آورد.

## قابلیت‌ها

- **برنامهٔ تمرینی:** پنج جلسهٔ اصلی پرس ۱، کشش ۱، پا ۱، بالاتنه ۲ و پایین‌تنه ۲؛ به‌علاوهٔ یک جلسهٔ اختیاری و کم‌خستگی برای حرکات کمکی و یادآوری روز استراحت.
- **آموزش حرکت‌ها:** راهنمای آماده‌سازی، تنظیم دستگاه و سیم‌کش، مراحل حرکت، تنفس، سرعت اجرا، نکته‌های ایمنی، اشتباه‌های رایج و نسخهٔ هر حرکت. با انتخاب هر مرحله از مراحل حرکت، مدل سه‌بعدی همان وضعیت را نشان می‌دهد و روی آن می‌ایستد. نام مرحله‌ها همان نام‌هایی است که حلقهٔ پویانمایی با آن‌ها ساخته شده، پس فهرست مراحل و نمایشگر همیشه یک چیز می‌گویند.
- **ظاهر «مجسمه» مدل:** مدل به‌صورت پیش‌فرض با ظاهر مانکنِ خنثی نمایش داده می‌شود — پوست روشن و کیت تیرهٔ تمرین — چون همان چیزی است که بدن را در اپ‌های آموزشی خوانا می‌کند. با کلید «بافت اصلی» همان مدل دقیقاً با بافت‌های فایل نمایش داده می‌شود. رنگ‌ها برای هر مش این مدل تعریف شده‌اند؛ مشی که در سیاهه نباشد بافت خودش را نگه می‌دارد.
- **نمای عضلات:** با یک کلید در نمایشگر سه‌بعدی، بدنهٔ مدل به مانکن خنثی تبدیل می‌شود و عضلات درگیر حرکت — عضلهٔ اصلی پررنگ و عضلهٔ کمکی کم‌رنگ — روی همان بدن روشن می‌شوند. نقشه در حالت استراحت مدل اندازه‌گیری می‌شود و رنگ هر رأس یک‌بار نوشته می‌شود؛ در جریان پخش حلقه، همان رنگ‌ها با پوست حرکت می‌کنند و هزینهٔ فریمی ندارند. این نقشه از عضلاتی می‌آید که خود برنامه برای هر حرکت فهرست کرده و اندازه‌گیری فعالیت عضلانی نیست؛ نام‌های عضلانی‌ای که نقشه نمی‌شناسد در همان صفحه گزارش می‌شود.
- **هیکل ورزشکاری مدل:** مدل CC0 در همان بارگذاری اول، در نواحی عضلانی به‌اندازهٔ کسری از قدِ خودش (حدود ۵ تا ۲۰ میلی‌متر) در جهت نرمالِ سطح حجیم می‌شود تا شبیه کسی باشد که تمرین می‌کند؛ اسکلت دست‌نخورده می‌ماند، پس همهٔ حلقه‌های حرکتی روی همین بدنِ حجیم‌تر پخش می‌شوند. انجام این کار یک‌بار برای هر صحنه و پیش از خواندن حالت استراحت است، و `tests/muscles.test.ts` رشد نواحی، دست‌نخورده‌ماندن جمجمه و پاها و تکرارپذیری (نشدنِ رشد دوباره) را نگه می‌دارد.
- **نمایشگر سه‌بعدی حرکت:** یک مدل انسانیِ پوشیده و rigged با مجوز CC0 در برنامه است و صفحهٔ هر حرکت، حلقهٔ پویانمایی همان حرکت را روی اسکلت همین مدل پخش می‌کند: کنترل پخش/توقف، شروع دوباره، سرعت ۰٫۵/۱/۱٫۵ و سه زاویهٔ روبه‌رو، پهلو و پشت. کنار نمایشگر، مرحلهٔ فعلی حرکت و «استانداردهای فرم همین حرکت» نشان داده می‌شود. پویانمایی از کتابخانهٔ حرکت خود برنامه ساخته می‌شود (کلیپ آمادهٔ بیرونی وجود ندارد) و راهنمای فرم است، نه جایگزین مربی یا ویدیوی اجرای واقعی. منشأ و اثر انگشت فایل مدل در `public/models/README.md` ثبت شده است.
- **ثبت تمرین:** ثبت وزنه، تکرار، تکرار در ذخیره (RIR) و یادداشت ست؛ نکته‌های فرم همین حرکت در همان کارت تمرین و به‌صورت تاشو در دسترس‌اند؛ نمایش عملکرد ثبت‌شدهٔ قبلی؛ ذخیرهٔ جلسهٔ فعال؛ و زمان‌سنج استراحت با مکث، پایان زودهنگام و تنظیم ۱۵ ثانیه‌ای.
- **پیشرفت دوگانه:** تنها پس از رسیدن همهٔ ست‌های برنامه‌ریزی‌شده به بیشترین تکرار بازه و حفظ حداقل RIR تعیین‌شده، افزایش کوچک وزنه را برای بررسی پیشنهاد می‌کند. برنامه هرگز وزنه را خودکار بالا نمی‌برد.
- **پیشرفت و سوابق:** سوابق جلسه، ست‌های ثبت‌شده، بهترین ست‌ها، نمودار وزنهٔ کاری و روند وزن بدن.
- **تغذیه:** هدف‌های قابل‌تنظیم کالری و درشت‌مغذی‌ها، ثبت روزانهٔ خوراک و بازهٔ پروتئین بر اساس وزن فعلی پروفایل. نیاز کالری قطعی یا تجویز پزشکی فرض نمی‌شود.
- **ذخیره‌سازی محلی و نصب‌پذیری:** تمرین‌ها و پروفایل در IndexedDB همین دستگاه ذخیره می‌شوند. پوستهٔ برنامه و فایل مدل مرجع در نسخهٔ نصب‌شده برای دسترسی آفلاین cache می‌شوند؛ کد سه‌بعدی فقط هنگام بازکردن نمایشگر بارگیری می‌شود.
- **پشتیبان‌گیری:** از بخش پروفایل و تنظیمات، نسخهٔ JSON از پروفایل و گزارش‌ها دریافت کن.
- **رابط فارسی و راست‌به‌چپ:** نوشته‌ها، تاریخ‌های نمایشی، اعداد و چیدمان رابط برای زبان فارسی تنظیم شده‌اند؛ قالب تاریخ‌های ذخیره‌شده همچنان ISO/Gregorian باقی می‌ماند تا سازگاری داده‌ها حفظ شود.

وزنه‌هایی که در پروفایل اولیه گزارش شده‌اند فقط **برآوردهای تأییدنشدهٔ وزنهٔ کاری** هستند؛ نه رکورد یک‌تکرار بیشینه، نه ست ثبت‌شده، نه عملکرد قبلی و نه رکورد شخصی. هیچ سابقه یا رکوردی ساختگی نیست.

## فناوری‌ها

- React 19، TypeScript و Vite 8
- React Router برای مسیرهای برنامه
- Dexie و IndexedDB برای ذخیره‌سازی محلی
- Three.js و React Three Fiber برای نمایشگر سه‌بعدی اختیاری و تنبل
- موتور حرکت اختصاصی در `src/motion/`: نمونه‌برداری حلقه‌ها، حل تماس کف پا با زمین و نوشتن ژست روی استخوان‌های همان GLB
- افزونهٔ Vite PWA و Workbox برای نصب‌پذیری و ذخیرهٔ فایل‌ها در حافظهٔ آفلاین
- قلم Vazirmatn به‌صورت محلی از بستهٔ npm؛ بدون وابستگی به سرویس قلم خارجی در زمان اجرا
- Vitest، Testing Library و fake-indexeddb برای آزمون‌ها
- CSS واکنش‌گرا و اختصاصی؛ بدون تصویر خارجی یا دارایی دارای حق نشرِ تأییدنشده

## نصب و اجرا

```bash
npm ci
npm run dev
```

Vite روی `0.0.0.0` اجرا می‌شود تا از دستگاه‌های دیگر شبکه و محیط پیش‌نمایش نیز در دسترس باشد. برای آزمایش با تلفن همراه در همان شبکه، نشانی LAN رایانه را باز کن و در صورت نیاز دسترسی سرور توسعه را در دیوارهٔ آتش مجاز کن.

## فرمان‌ها

```bash
npm run dev       # اجرای سرور توسعه
npm run build     # بررسی TypeScript و ساخت نسخهٔ نهایی
npm run build:offline  # ساخت نسخهٔ تک‌فایلی برای اجرای محلی
npm run fetch:model      # دریافت و بررسی SHA-256 مدل 3D از منبع ثبت‌شده
npm test          # اجرای آزمون‌ها
npm run test:watch
npm run preview   # اجرای محلی نسخهٔ ساخته‌شده
```

## متغیرهای محیطی

نیازی به متغیر محیطی نیست. میتی سرور، حساب کاربری، کلید API یا ابزار تحلیل شخص ثالث ندارد.

## نسخهٔ اصلاح‌شده و اجرای محلی

این نسخه از یک patch متنی بازسازی شده است. خودِ patch باینری `public/models/human.glb` را حمل نمی‌کند؛ بنابراین برای فعال‌شدن نمایشگر سه‌بعدی باید همان مدل CC0 ثبت‌شده در `public/models/README.md` را در آن مسیر قرار داد. برنامه در نبود مدل کرش نمی‌کند و حالت جایگزین آموزشی نشان می‌دهد. برای ساخت یک فایل HTML مستقل از `npm run build:offline` استفاده کن؛ این حالت کد و فایل مدل موجود را در یک HTML قرار می‌دهد. اگر `human.glb` را نداری، ابتدا `npm run fetch:model` را اجرا کن تا فایل با SHA-256 ثبت‌شده دریافت و بررسی شود.

## داده و حریم خصوصی

داده‌ها فقط در IndexedDB مرورگر فعلی ذخیره می‌شوند و به مرورگر یا دستگاه دیگری همگام‌سازی نمی‌شوند. پاک‌کردن داده‌های سایت ممکن است آن‌ها را حذف کند. پیش از پاک‌کردن حافظه یا جابه‌جایی دستگاه، نسخهٔ JSON پشتیبان بگیر. هیچ رمز یا فایل `.env` در مخزن لازم نیست.

## دارایی سه‌بعدی و پویانمایی حرکت‌ها

`public/models/human.glb` یک مدل انسان با پوشش روزمره و ۵۳ استخوان است؛ مجوز اعلام‌شدهٔ فایل CC0 1.0 است. این فایل حدود ۶۷۲ کیلوبایت است و کلیپ پویانمایی از پیش ساخته‌شده ندارد. جزئیات منبع، مجوز و SHA-256 در `public/models/README.md` آمده است. مدل در بستهٔ آفلاین PWA نیز cache می‌شود.

پویانمایی هر حرکت، کارِ خودِ برنامه روی همین ریگ است، نه یک دارایی واردشده:

```text
src/motion/types.ts       قراردادهای حرکت، تجهیزات، سکو و استانداردهای فرم
src/motion/skeleton.ts    خواندن حالت استراحت مدل و محور لولاهای واقعی
src/motion/sampler.ts     نمونه‌گیری حلقه و نوشتن آن روی استخوان‌ها + حل تماس با زمین
src/motion/armPoses.ts    زاویه‌های شانه و آرنج برازش‌شده (تولیدشده، دستی ویرایش نکن)
src/motion/library.ts     ۳۲ حرکت فارسی، هر کدام با حلقهٔ پنج‌کلیدی و استانداردهای فرم
src/motion/modelRig.ts    اتصال حلقه به صحنهٔ بارگیری‌شده در مرورگر
src/motion/props.ts       ساخت هالتر، دمبل، سیم‌کش و سکو/صندلی برای نمایشگر سه‌بعدی
src/motion/muscles.ts     نقشهٔ عضلات روی بدن (نمای عضلات) و هیکل ورزشکاری مدل
tools/arm-solve.ts        حل‌کنندهٔ آفلاین زاویه‌های بازو
tools/motion-report.ts    گزارش عددی مفصل‌ها برای بازرسی یک حرکت
tools/motion-angles.ts    جدول دامنهٔ مفصل‌ها، زاویهٔ گردن و گاردهای آناتومی
tools/seat-fit.ts         برازش صندلی، پشتی و تکیه‌گاه سینه روی ژست واقعی حرکت
tools/render_poses.py     رندر آفلاین شیت ژست‌ها برای بازبینی چشمی (نیازمند Pillow)
```

صندلی و تکیه‌گاه‌ها روی ژست اندازه‌گیری می‌شوند، نه با حدس: `npx vite-node tools/seat-fit.ts` اعداد را چاپ می‌کند و همان‌ها در `library.ts` به‌شکل `seatFixture` می‌نشینند. سه دستگاه نشسته (جلو پا، پشت پا، ساق نشسته) ریشه را به‌جای کف پا ثابت می‌کنند، چون خودِ دستگاه لگن را نگه می‌دارد و تنها ساق حرکت می‌کند. بازبینی چشمی هم با `python tools/render_poses.py <ids…>` و شیت‌های `/tmp/pose-sheets/` انجام می‌شود؛ تست `tests/motion-anatomy.test.ts` مطمئن می‌شود لگن روی صندلی و سینه روی تکیه‌گاه می‌ماند.

افزودن حرکت تازه: یک سازنده در `src/motion/library.ts` بنویس، `motionId` را در `src/data/exercises.ts` به آن حرکت بده و `npm test` بگیر. تست‌های `tests/motion-library.test.ts` و `tests/motion-rig.test.ts` پایداری تبدیل‌ها، تماس کف پا با زمین، وجود هر پنج مرحله و قابل‌پخش‌بودن حلقه روی ریگ را بررسی می‌کنند.

افزودن کلیپ آمادهٔ بیرونی (اختیاری، برای آینده): هر دارایی تازه باید منشأ، مجوز بازتوزیع، ریگ سازگار و تناسب با همان تمرین داشته باشد و باید در `public/models/README.md` ثبت شود. انیمیشن مشابه یا تصادفی را به‌جای فرم همان حرکت جا نزن؛ اگر کلیپی موجود نیست، همان نمایش ریگ‌محور و راهنمای نوشتاری کافی است.

## بررسی حرکت سه‌بعدی و ساخت آفلاین

برای اجرای قابل‌تکرار آزمون‌های حرکت روی ویندوز، بعد از استخراج پروژه، PowerShell را در پوشهٔ اصلی باز کن:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\RUN-MOTION-AUDIT.ps1
```

این اسکریپت Node.js 22.12 یا بالاتر می‌خواهد و نصب وابستگی‌ها و دریافت مدل مرجع از اینترنت را در مرحلهٔ آماده‌سازی انجام می‌دهد. فایل مدل با SHA-256 پین‌شده بررسی می‌شود؛ سپس تست‌های متمرکزِ حرکت، گرفتن وسیله، آناتومی و مسیر ریگ، کل تست‌ها، build و بسته‌بندی تک‌فایلی اجرا می‌شوند. گزارش در `motion-audit-log.txt` ذخیره می‌شود.

دستورات مستقل:

- `npm run audit:motion` — بررسی ایستای کد حرکت؛ **جایگزین رندر یا تأیید فرم نیست**.
- `npm run fetch:model` — دریافت مدل پین‌شده، در محیطی با اینترنت.
- `npm run verify:model` — اعتبارسنجی ساختار GLB و SHA-256.
- `npm run verify:offline` — بررسی مقدماتی HTML تک‌فایلی پس از `npm run build:offline`.

معیارها و محدودیت‌ها در فایل `MOTION-VALIDATION-FA.md` توضیح داده شده‌اند. حتی پس از سبزشدن تست‌های عددی، پنج حرکت نخست باید از روبه‌رو و پهلو بازبینی شوند؛ تست خودکار به‌تنهایی صحت بصری حرکت را ثابت نمی‌کند.

## بهینه‌سازی بارگذاری

اپ روی پوستهٔ سبک بنا شده است تا باز کردن آن روی موبایل و اینترنت کند هم سریع بماند:

- تنها صفحهٔ خانه همراه پوسته می‌آید؛ بقیهٔ مسیرها با `React.lazy` و یک حالت انتظار فارسی بارگذاری می‌شوند.
- کتابخانهٔ تمرین‌ها، ۳۲ حرکت و نمایشگر سه‌بعدی در چانک‌های جدا هستند و تا باز نشدن صفحهٔ حرکت دانلود نمی‌شوند (three.js حدود ۸۱۴ کیلوبایت و مدل ۶۷۲ کیلوبایت است).
- نمایشگر، پویانمایی و مدل را در زمان بی‌کاری مرورگر گرم می‌کند؛ در حالت توقف هم ریگ دیگر شصت بار در ثانیه دوباره نمونه‌گیری نمی‌شود.
- سرویس‌ورکر مدل `human.glb` و دارایی‌های سه‌بعدی را برای استفادهٔ آفلاین cache می‌کند؛ مسیر مدل دیگر عمداً از precache کنار گذاشته نشده است.

نتیجهٔ ساخت نسخهٔ نهایی: چانک ورودی از حدود ۵۹۸ کیلوبایت (۱۶۹ کیلوبایت gzip) به حدود ۳۸۳ کیلوبایت (۱۲۲ کیلوبایت gzip) رسید و بایت‌های سه‌بعدی از مسیر ورود حذف شدند.

## ساخت و استقرار

```bash
npm ci
npm run build
```

برای اجرای عادی، پوشهٔ `dist/` را روی هر میزبان ایستای HTTPS که مسیریابی SPA را پشتیبانی می‌کند منتشر کن؛ مسیرهای ناشناخته باید به `/index.html` برگردند. سرویس‌ورکر PWA هنگام ساخت نسخهٔ نهایی تولید می‌شود. سرور یا پیکربندی محیطی جداگانه لازم نیست.

## یادآوری ایمنی

میتی آموزش و ثبت عمومی تمرین ارائه می‌دهد و جایگزین توصیهٔ پزشکی یا تشخیص فردی نیست. از وزنه و دامنه‌ای استفاده کن که کنترل می‌کنی؛ اگر حرکتی درد تیز ایجاد کرد، متوقف شو و در صورت نیاز از متخصص واجد صلاحیت راهنمایی بگیر.
